Chapter 01

Pick a tab. Stay in flow.

No mode-switching between five apps. The model picker, the attachments, the voice button — same everywhere. What changes is what the agent is allowed to promise you.

i.

Code — the workshop

Bring a repo. Leave with a diff.

Plan read-only, Ask for the usual, Auto when you want it to keep going and fix its own failures. Every change ends in a Monaco diff you can revert file-by-file — or nuke the whole run with Undo.

Try: fix the flaky test in auth/, then show me the diff

  • typecheck + targeted tests, then auto-repair
  • opt-in worktree per session, one-click merge
  • real PTY, dev servers, agent-driven browser

ii.

Home — the desk

No repo. Just the thing you need.

Research, then a file that actually exists: a Word report, a deck, a spreadsheet, a PDF. It lands in ~/Documents/Nexus, owned by the chat that made it, previewed in-app, downloaded wherever you want.

Try: research EV tariffs and draft me a 2-page brief (.docx)

  • web search with real sources, not vibes
  • throwaway generator scripts cleaned up after
  • images, PDFs, voice — straight into the prompt

iii.

Notebook — the archive

Ask your documents. Get receipts.

Drop in the PDFs, the contracts, the field notes. Every answer carries [S1]-style citations you can click open — plus a verdict: grounded, partial, or ungrounded. Scope sources in and out per question.

Try: compare what §4 and §7 say about termination

  • hybrid retrieval, passage inspector, quizzes
  • save anything as a cited studio note
  • works offline with local embeddings

Chapter 02

Built like a workbench, not a demo.

The unglamorous parts are the point: verification before praise, transcripts you can audit, keys that never leave the machine.

Verify, then talk
Code runs go brief → agent → verify → repair. Typecheck and targeted tests run first; failures go back to the agent with the transcript intact. Plan mode skips all of it and just writes the plan.
Your keys stay home
15 providers — OpenAI, Anthropic, Gemini, Mistral, Groq, xAI, OpenRouter, Ollama, DeepSeek, Zen, Together, Fireworks, Azure, Bedrock, anything OpenAI-compatible. Secrets live in OS-encrypted storage, decrypted only in memory.
Undo is a feature
Disk snapshots before every run. A run you hate is one click from never having happened. Worktrees are opt-in, telemetry survives discards, and .nexus/ never pollutes your diff.
Extend it your way
MCP servers (stdio/http/sse), SKILL.md playbooks global or per-project, auto-loaded project rules, slash commands with / — including your own .nexus/commands/*.md.
A browser the agent can touch
Isolated partitions per tab, a hidden executor for the agent (click, fill, scroll, screenshot), and a Watching toggle so the sidebar follows along live over your dev server.
Updates that don't nag
Installed builds check for updates on launch, download quietly, and offer one restart-to-install pill. Portable stays portable — re-download when you feel like it.

Chapter 04

No sandbox. No theater.

Nexus runs real commands on your machine with your privileges — installs, scripts, MCP tools, all of it. A deny-list blocks catastrophes (rm -rf / and friends) and risky moves ask first (pushes, installs, curl | sh). Everything else just runs. If that sentence worries you, run Nexus in a VM. We'd rather tell you than surprise you.
